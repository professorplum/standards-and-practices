# Tech Radar: Languages & Runtimes

**Version:** 1.0  
**Status:** Active  
**Owner:** Engineering Leadership  
**Last Updated:** 2026-07-31

---

## Languages

| Technology | Ring | Notes |
|---|---|---|
| **TypeScript** | ✅ Approved | Primary language for all new services. Strict mode required. |
| **Go** | ✅ Approved | Primary language for performance-sensitive services and CLI tooling. |
| **Python** | 🔵 Trial | Approved for data pipelines, ML workloads, and scripting. Not for primary API services without ADR justification. |
| **JavaScript (plain)** | ⚠️ Restricted | Permitted only in frontend code where TypeScript is not supported. All new frontend code must use TypeScript. |
| **Bash / Shell** | ⚠️ Restricted | Permitted for CI scripts and simple automation only. Must not contain business logic. Maximum ~50 lines; anything larger should use a proper language. |
| **Java** | ⚠️ Restricted | Permitted only in services that already use Java. No new Java services without ADR and team lead approval. |
| **Ruby** | 🚫 Banned | No new Ruby code. Existing Ruby must be tracked for migration. |
| **PHP** | 🚫 Banned | No new PHP code. |

---

## Runtimes & Versions

| Runtime | Approved Version Range | Notes |
|---|---|---|
| **Node.js** | LTS versions only (≥ 20.x) | Pin the exact minor version in Dockerfiles. |
| **Go** | ≥ 1.21 | Use the latest stable 1.x. |
| **Python** | ≥ 3.11 | Use `pyproject.toml` for dependency management. |
| **JVM** | OpenJDK ≥ 21 | For restricted Java services only. |

---

## Package Managers

| Technology | Ring | Notes |
|---|---|---|
| **npm / npx** | ✅ Approved | Use `package-lock.json` for reproducible builds. Pin exact versions in production. |
| **pnpm** | 🔵 Trial | Permitted; evaluate for monorepo use cases. |
| **yarn classic (v1)** | ⚠️ Restricted | Existing projects may continue. No new projects. |
| **yarn berry (v2+)** | ⚠️ Restricted | Permitted only with explicit team lead approval; PnP mode disabled unless justified. |
| **Go modules** | ✅ Approved | Standard for Go. |
| **pip + pip-tools** | ✅ Approved | Standard for Python. Use `requirements.txt` generated by `pip-tools`. |
| **Poetry** | 🔵 Trial | Permitted for Python services; evaluate ergonomics. |
